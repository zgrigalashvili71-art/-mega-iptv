MEGA IPTV - QUICK START

1. Put START_MEGA_IPTV.bat and Build_Mega_IPTV.ps1 in the same folder.
2. Double-click START_MEGA_IPTV.bat.
3. Wait until it prints "AQUAPLAY URL".
4. On Xiaomi TV Box -> AquaPlay -> Add M3U URL.
5. Enter the displayed URL, for example:
   http://192.168.0.123:8080/ALL_TV_PLUS_SPORTS.m3u
6. Keep the laptop window open while using that URL.

The script downloads and merges several public/free IPTV lists and removes exact duplicate stream URLs.
It does not unlock paid channels or bypass subscriptions/geographic access controls.

If Windows Firewall asks, allow PowerShell on PRIVATE networks only.
